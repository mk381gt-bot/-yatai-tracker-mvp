## 処理と注意
- Wikisource の分は、ウィキ記法（テンプレート・リンク・タグ）を機械的に取り除いただけで、本文には手を加えていない。ルビは「漢字《よみ》」の形にした。まれに見出しや注の形が崩れている。
- Wikisource の翻刻には、底本の違い・入力ミス・外字の「■」「〓」がある。**引用するときは校訂本（新編日本古典文学全集、中華書局本など）と照合すること。**
- 青空文庫の分は Shift_JIS から UTF-8 に変換し、改行を LF にそろえただけ。末尾の底本・入力者の表記はそのまま残している（青空文庫の利用条件）。
- 風土記逸文（06）は OCR ではなく、Claude が画像を見て読んだもの。読み誤りがありうるので、画像で確かめること。
- 和名類聚抄の一覧では、豊後国と対馬島で郡と郷の対応がずれている所がある（ファイル内に注記）。
