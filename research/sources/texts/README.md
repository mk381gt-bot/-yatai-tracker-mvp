## 処理と注意
- Wikisource の分は、ウィキ記法（テンプレート・リンク・タグ）だけを機械的に取り除き、本文には手を加えていない。ルビは「漢字《よみ》」の形にした。取り除き方の都合で、まれに見出しや注の形が崩れている所がある。
- Wikisource の翻刻には、底本の違い・入力ミス・外字の「■」「〓」がある。**引用するときは校訂本（新編日本古典文学全集、中華書局本など）と照合すること**。
- 青空文庫の分は、Shift_JIS から UTF-8 に変換しただけで、末尾の底本・入力者の表記もそのまま残している（青空文庫の利用条件）。
