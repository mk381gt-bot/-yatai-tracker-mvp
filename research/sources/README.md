## 確かさについて
- **01・03** は、公開されているテキストデータから機械的に取り出したので、転記ミスはない。ただし元データ自体に誤字がある（例：「正始元年」が「正治元年」）。気づいた所には校異を付けたが、**全文の照合はしていない**。
- **04** は、このセッションでは原文サイトに接続できなかったため、記憶から書いた。よく知られた短い箇所に限ったが、字の違いはありうる。
- 『古事記』『日本書紀』の全文は、ここには入れていない（取得できなかった）。必要なら 04 の末尾の「校合に使う本」から入手する。
