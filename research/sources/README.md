## 確かさについて
- **01・03** は、公開されているテキストデータから機械的に取り出したので、転記ミスはない。ただし元データ自体に誤字がある（例：「正始元年」が「正治元年」）。気づいた所には校異を付けたが、**全文の照合はしていない**。
- **04** は最初は記憶から書いたが、そのあと取得した原文と照合し、細かい違いを直した。
- 全文は [texts/](./texts/README.md) にある。
