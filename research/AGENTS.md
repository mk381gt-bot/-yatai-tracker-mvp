# AGENTS.md — research/（ヒミコの決断のための資料集）

このフォルダは、卑弥呼（2世紀後半〜3世紀中頃）の決断を考えるための**歴史・考古学の資料集**です。リポジトリ本体（屋台トラッカー）のコードとは関係ありません。AI エージェント（Codex、Claude Code など）がこのフォルダで作業するときは、以下に従ってください。

## まず読むもの
1. `catalog.json` — 全ファイルの目録。各ファイルの `kind`（種類）・`origin`（どう作ったか）・`license`・`caveat`（注意点）が入っている。**ファイルを探すときはまずここを見る。**
2. `README.md` — 人間向けの目次。
3. 内容の要約が必要なら `notes/01_*.md` と `notes/02_*.md`。

## フォルダ構成
| パス | 中身 |
|---|---|
| `notes/` | 調査ノート（Claude が執筆）。論文・報告書の要点、確度ラベル付き |
| `data/` | 表データ（CSV, UTF-8, ヘッダーあり）。年表・遺跡・比定・ファクトチェック・決断の場面・文献・郷名 |
| `sources/excerpts/` | 一次史料の抜粋と現代語訳（倭人伝など） |
| `sources/texts/` | 一次史料の全文（古事記・日本書紀・風土記・中国正史など）と、1910年の古典的論文 |
| `sources/texts/fudoki/scans_kurita1927_kyushu/` | 風土記逸文の底本の画像（国立国会図書館、著作権切れ） |
| `tools/` | `build_catalog.py`（目録の作り直し）、`check.py`（リンクと根拠パスの検査） |

## 守ること
- **事実と解釈を混ぜない。** 文中のラベルは次のとおり。新しく書く文章にも必ず付ける。
  - `[A]` 査読論文・研究報告・原文で確認 ／ `[B]` 公的機関の解説で確認 ／ `[C]` 学説・解釈・論争中 ／ `[※]` 原典未確認
  - ファクトチェックの判定は `○`（合う）・`△`（一部）・`✕`（合わない）・`？`（判定不能）
- **史料の原文を書き換えない。** `sources/texts/` と `sources/excerpts/*_original.md` の本文は取得したままにしてある。誤字の指摘は本文を直さず、注（「校異」「注」）として足す。
- **主張には根拠のパスを付ける。** `data/*.csv` の `source_refs` には、このフォルダからの相対パスを `;` 区切りで書く。存在しないパスを書かない。
- **記憶で史料を引用しない。** 原文が必要なら `sources/texts/` を検索する（例：`grep -rn "卑彌呼" sources/texts`）。見つからなければ「未取得」と書く。
- **書き起こしは画像で確かめる。** `sources/texts/fudoki/06_itsubun_kyushu_kurita1927.md` は Claude が画像から読んだもの。疑わしい字は `scans_kurita1927_kyushu/R0xxx.jpg` を見る（底本のページ番号は各条の末尾）。
- **ライセンスに注意する。**
  - `sources/texts/wamyosho/` と `data/wamyosho_townships.csv` は **CC BY-NC-SA 4.0（非営利・継承）**。営利目的の成果物（販売するゲームなど）には、元データの作成者の許諾なしに使わない。
  - それ以外の原文はパブリックドメイン。notes・data・訳文はこのプロジェクトのもの。

## ファイルを追加・変更したら
```bash
cd research
python3 tools/build_catalog.py   # 新しいファイルは、先に tools/build_catalog.py の RULES に1行足す
python3 tools/check.py           # 0 problem(s) になるまで直す
```
- ファイル名は英数字・`_`・`-` だけにする（日本語の題名はファイルの1行目の見出しに書く）。
- 本文は UTF-8、改行は LF。

## 文字と検索のこつ
- 漢文の原文は旧字体が多い（例：「卑彌呼」「臺與」「國」「於」）。新字体（「卑弥呼」）だけで検索すると漏れる。
- `sources/excerpts/sanguozhi_dongyi_original.md` だけは**簡体字**（「卑弥呼」「带方」）。
- 日本書紀は `nihonshoki_05.md`＝崇神紀（箸墓）、`_07`＝景行紀（九州）、`_09`＝神功皇后紀（魏志の引用）。
