# 01_PRIMARY_EXPERIENCES — 一次経験の棚卸し（目標30例）

状態: **収集中（1 / 30）**
方式: 対話で1回あたり最大3問。AIは事例を作らない。

---

## このファイルの目的

> **「なぜその一手を選んだのか」に、事例をまたいで共通する選択基準が存在するか。**

存在すれば「戦略的」と呼べる。存在しなければ、この概念は思考法ではなく「行動する習慣」であり、
名称も売り方も根本から変わる。**30例を集める目的はこれ一つ。**

## 原則

1. **AIは事例を作らない。** 本人の実体験のみ。
2. **理論調査より先に書く。** 後で読むと記憶が理論の言葉に整形される。
3. **成功例を選ばない。** A に偏らせない。C・D・E・F を意図的に取りに行く。
4. **うまくいった理由を先に書かない。** 起きたことを書く。解釈は後のフェーズ。

## 分類

| 記号 | 内容 | 扱い |
|---|---|---|
| **A** | 今すぐ解決できない制約の中で、一手を打った | 中心 |
| **B** | 通常の改善で解決した | 比較対象（発動条件の外） |
| **C** | 何もできなかった | 境界データ。なぜ動けなかったかが重要 |
| **D** | 無理に前向きに意味づけした | 誤用 |
| **E** | 制約を利用しようとして逆効果になった | **誤用。最重要** |
| **F** | その時は意識していなかったが、後から価値に気づいた | 後付け解釈の検出用 |

**A が7割を超えたら、選び方が偏っている。** C・D・E・F が合計で2割を下回る場合、
この事例集は自分に都合のよい証拠集めになっている可能性が高い。

```
### Case NN ［分類: 　］［時期: 　］［場面: 　］

```

### 項目6の書き方（ここが研究の本体）

「なんとなく」で終わらせない。答えにくいときは、次の4つで分解する。

- **本来ならどうしていたか**（＝他の現場・普段なら選んだ手）← 発見2により追加。最優先で聞く
- **何を守ろうとしたか**（安全 / 時間 / 金 / 相手の機嫌 / 自分の立場 / 信用 / その場の進行）
- **何を捨てたか** — 選択基準は、選んだものより**捨てたもの**に表れる
- **他の選択肢をなぜ捨てたか**（項目4で挙げたもの一つ一つについて）
- **どれくらいの時間で決めたか**（即座 / 数秒 / 迷った / 後から思いついた）

※ 後から思いついた場合は、**分類はF寄り**になる。正直に書く。

### 項目9・10について
- **9 が空欄ばかりの事例集は信用できない。** 副作用を思い出せない場合は「思い出せない」と書く。
- **10 で「いいえ」「条件付き」だった事例が、後の境界線（06）の材料**になる。

### 発見1: 分類は「立場」によって変わる（2026-10-01・Case 01 から）

Case 01 の事実関係は一つだが、見る位置で分類が変わる。

| 立場 | その人にとっての分類 |
|---|---|
| 現場責任者（テープ不可を決めた人） | **D（改善放棄）** — 美観を理由にリスク低減措置を見送っている |
| 外注の本人（決定権がない） | **A（制約下の一手）** — 権限がない中で取れる手を打っている |

**含意（重要）**
1. **A と D の境界は、行動ではなく「その人に決定権があったか」で決まる。** 判定テストは行動を見るのではなく権限を見るべき。
2. **教える相手によって、同じ教材が危険になる。** 決定権を持つ人（管理職・経営者）にこの思想を教えると、D（改善放棄）を正当化する道具になりやすい。決定権のない人（現場スタッフ・外注・新人）に教えるぶんには、その危険が小さい。
   → **商品の対象読者は「決定権を持たない立場の人」に寄せた方が、誤用リスクが構造的に低い**【推】。これは `11_PRODUCT_PLAN.md` と `06_MISUSE_AND_BOUNDARIES.md` に効く。
3. 逆に、組織向け研修で管理職に売る場合は、第4層（記録・報告）を必須にしないと、この思想は**責任者が安全対策を見送る言い訳**として機能しうる。

### 発見2: 発動の引き金は「自分の標準手順が封じられたこと」（2026-10-01・Case 01 項目6から）

本人の回答: 「他の現場だったら、普通に養生をして事故を防ぐって考えるから」

これが意味すること。声掛けは思いつきではなく、**本来選ぶはずだった手（養生）が使えないと分かったことによって選ばれた代替手段**である。

```
通常:  危険を見る → 養生する（B・改善）           ← 本人の標準手順
今回:  危険を見る → 養生が封じられている → 代替を探す → 声掛け（A）
```

**含意1: 第1層の記述がより正確になる。**
現在の第1層は「今すぐには問題・制約そのものを解消できない」。
実際に本人の内側で起きていたのは、より具体的に「**自分がいつもやる手が、この現場では使えない**」という認識だった。
発動条件は客観的な解決不可能性ではなく、**本人の標準手順が封じられたという認識**である可能性がある。
（定義は30例まで変更しない取り決めなので、ここでは変更せず記録に留める）

**含意2: これは熟練者の思考法である可能性が高い。【重要】**
「養生する」という正解を持っているから、それが封じられたことに気づける。
**標準手順を持っていない人は、制約にも気づかない。** 危険を見ても「何が封じられているか」が分からない。
→ この思想は**新人向け教材として成立しにくい**。対象読者は「自分の標準手順を持っている人」。
→ `11_PRODUCT_PLAN.md` に直結する。発見1（決定権を持たない人向け）と合わせると、
   対象像は「**標準手順は持っているが、決定権は持っていない人**」に絞られる。
   具体的には、現場の職人・外注・派遣・中堅スタッフ・サブリーダー層。これはかなり明確な読者像である。

**含意3: 選択基準の第一候補が出た。**
> **目的は保持したまま、手段だけを差し替える。**

- 養生（手段）は使えない → 事故防止（目的）は捨てない → 声掛け（別の手段）に差し替える
- これはポジティブ思考と違う（意味づけを変えていない。目的も手段も現実のまま）
- これは改善放棄と違う（目的を捨てていない）
- 営業につながったのは**副産物**であり、選択の理由ではない（＝第3層が任意でよいことの裏付け）

**ただし1件からの推論である。** 残り29例で同じ構造が繰り返されるかを確認するまで、原則とは呼べない。
検証方法: 各事例の項目6で「本来ならどうしていたか」を必ず聞く。それが毎回存在するなら、この構造は実在する。

### 30例そろった時点で行う分析

1. **項目6の横断分析（本命）** — 「守ろうとしたもの」を全事例で並べ、優先順位に共通構造があるか見る。
   共通構造があれば、それが「戦略的」の中身になる。
2. **「捨てたもの」の分析** — 何を犠牲にする判断が繰り返されているか。ここに思想の負の側面が出る。
3. **判断時間の分布** — 即座が多ければ「型」として教えられる。迷いが多ければ、教えるべきは型ではなく判断材料。
4. **第3層（二重効果）の出現率** — A のうち項目8が埋まる割合。大半なら、二重効果は実態として必須に近く、層の配置を見直す材料になる。
5. **第4層（記録・報告）の出現率** — 項目5に記録・報告が含まれる割合。低ければ、ガードレールは意識しないと働かないことの裏付けになる。
6. **F の比率** — 高ければ後付け解釈の疑いが強い。第1層・第2層の「その場で実行した」を厳格に運用する必要がある。
