# 「戦略的プラス思考」研究

現場（接客・営業・飲食・イベント・現場仕事）で使える実務的な思考法として成立するかを検証し、
成立した場合に note / PDF / 書籍 / 研修 へ展開するための研究リポジトリ。

**この研究の姿勢: 肯定から始めない。独自性が無ければ無いと書く。**

---

## 現在の結論（2026-09-16 時点）

| 項目 | 判定 |
|---|---|
| 概念として成立しているか | **未成立**。定義が広すぎ、反証不可能な状態 |
| 素材としての見込み | **あり**。事例駆動と境界線設計の方針は正しい |
| 独自性 | **未検証。現時点では低いと想定すべき**（レモネード原則・TRIZ原理22・リフレーミングと重複する恐れ） |
| 最大の脆弱性 | 原点の「段差」の例が、安全管理の原則（危険は除去が最優先）と衝突しうる |
| 最も有望な方向 | 「マイナスの処理を免除しない」という**順序の規律**を背骨に置く（定義案C） |
| 進めてよいか | **進めてよい。ただし順序を変える**（既存思想調査より先に、自分の実例100本の棚卸し） |

推奨する現時点の定義:
> マイナスが起きたとき、①まず本来の処理（減らす・消す・謝る）をやり切ったうえで、
> ②同じ出来事から次に使えるものを**一つだけ**持ち出す、という二本立ての対応を習慣にすること。
> マイナスを良いことだと思い込む技術ではない。**処理を免除しない**点がポジティブシンキングとの決定的な違い。

## 未解決の問題

1. 「マイナス」の定義域が決まっていない（危険／不便／失敗／不満／不明 などを同一に扱えるのか）
2. 「価値」の受け手が決まっていない（客／自分／組織／将来の客）→ 決まらないと効果測定ができない
3. **名称と定義が一致していない**。定義のどこにも「戦略」（長期・資源配分・選択と集中）の要素が無い
4. 思考法なのか、行動の型なのか、習慣なのか（商品の売り方が変わる）
5. 独自性がエフェクチュエーション／TRIZ／リフレーミングに侵食されないか（未検証）
6. 「クレームはチャンス」が、カスタマーハラスメント対策・感情労働の観点と矛盾しないか
7. 上司が部下に強要する道具にならないための条件
8. 読者（買い手）が誰か未定義

## 現在の仮定（Assumptions — すべて検証対象）

- A1. 現場の人は「前向きになる方法」ではなく「次に何をするか」を求めている【推・未検証】
- A2. 事例の密度が商品価値を決める（思想の新しさではない）【推】
- A3. 最も刺さる読者は「教える立場の人」（店長・現場リーダー・個人店主）【推・未検証】
- A4. 「処理を免除しない」という制約が、他のポジティブ系との差別化になる【推】
- A5. 一人で無理なく運営できる規模を優先する（本人の方針）【前提】
