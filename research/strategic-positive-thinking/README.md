# 「戦略的プラス思考」研究

**制約が残った状態でも停止しないための、実務的な判断法**を体系化できるかを検証する。
自己啓発ではなく、接客・営業・飲食・イベント・現場仕事・管理職・小規模事業・AI活用の現場で
**5〜30秒で使える判断ツール**として成立するかを問う。

**姿勢: 肯定から始めない。独自性が無ければ無いと書く。**

---

## 現在の定義（第3版・4層構造／2026-09-16 固定）

Phase 0.5（一次経験30例）の完了まで変更しない。

| 層 | 内容 | 位置づけ |
|---|---|---|
| **1 発動条件** | 今すぐには問題・制約そのものを解消できない。今すぐ自分の権限・時間・資源で解決できるなら、通常の改善を優先する | 適用範囲を決める |
| **2 最小成立条件** | 制約を事実として認識したうえで「この条件のままでも今できることは何か」と行動余地を探し、**一手を実行する** | ここまでで成立 |
| **3 より質の高い一手** | 可能であれば、本来の目的を守るだけでなく**別の価値も同時に生む**一手を選ぶ | **必須ではない**。質の指標 |
| **4 組織利用時のガードレール** | 記録／報告／改善ルートへの接続／残留問題の可視化 | **概念本体ではない**。組織運用時の安全装置 |

詳細と、この4層化がもたらす帰結（独自性の主張が「組み合わせの新規性」に移ること）は `00_CONCEPT_REVISION.md`。

### Phase 0.5 で答えを出す中心問題
> **「なぜその一手を選んだのか」に、事例をまたいで共通する選択基準が存在するか。**
> 存在すれば「戦略的」と呼べる。存在しなければ、これは思考法ではなく「行動する習慣」であり、名称も売り方も変わる。

## 現時点の結論

| 項目 | 判定 |
|---|---|
| 概念として成立しているか | **未成立（ただし第1版より大幅に前進）**。発動条件が定まり、「何にでも当てはまる」状態は解消された |
| 独自性 | **未判定。判定は30例の後まで行わない。** 二重効果と記録を任意層に移したため、最小成立条件だけでは既存概念（暫定措置・bricolage・satisficing）と区別しにくい |
| 独自性の主張の形 | 「第2層が新しい」ではなく「**第1〜4層をこの順序で組んだ全体が新しい**」。組み合わせの新規性を問う形になり、立証のハードルは上がった |
| 最大のリスク | **first-order problem solving の量産装置になること**。現場が上手にしのぐほど問題が表面化せず、恒久対策が永久に来ない |
| 安全面の整合 | **問題なし。むしろ整合する**。残留リスクの周知＋暫定措置＋計画的な恒久対策は安全実務の標準手順である（第1版の私の指摘は片手落ちだった） |
| 次にやること | **一次経験30例の収集**（`01_PRIMARY_EXPERIENCES.md`） |

### 境界の一文（現時点の最有力表現）
> **しのぐことと、諦めることは違う。違いは、記録が残っているかどうかである。**

## 未解決事項

1. 安全実務の「暫定措置」と何が違うのか（**最優先**。副次価値の選択基準を含むかで結論が変わる）
2. 要素④（記録・報告とのセット）を既に要求している既存概念があるか
3. Bricolage / Improvisation / Satisficing との差分（個人か組織か、秒単位か戦略か）
4. KAIZEN の「異常で止める」思想と、本研究の「止めずに一手」は矛盾しないか
5. 「制約下での行動選択」だけでは既存領域と重なる。上に載せる選択基準が持つか
6. 副次価値を狙いすぎて本来目的が薄まる場面の境界（クレーム客への営業など）
7. 経営側が「工夫しろ」と責任転嫁する道具にならないための条件
8. 名称（未確定。「戦略的プラス思考」は仮称。定義に「戦略」要素が薄い問題は継続）

## 次にやること（優先順）

1. **一次経験30例の収集**（`01_PRIMARY_EXPERIENCES.md`）— AIは事例を作らない。対話で1回あたり最大3問
   - 特に **E（利用して逆効果）**、**C（何もできなかった）**、**F（後から気づいた）** を意図的に集める
   - 項目6「なぜその一手を選んだか」を最重視する
2. 30例の分類集計と、項目6の横断分析 → 選択基準が存在するかの判定
3. Phase 1 ティア1の調査（`03_EXISTING_THEORIES.md`）
4. 独自性の判定（`04_DIFFERENCES.md`）

**30件そろうまで着手しないこと**: 名称確定 / 商品化 / 書籍構成 / 50本化 / 独自性の最終判定

## 棄却した仮説

| 棄却したもの | 日付 | 理由 |
|---|---|---|
| **第1版の定義「マイナスから次に使える価値を一つ取り出す」** | 2026-09-16 | 変換先が9つあり、何にでも当てはまる。反証不可能に近い。レモネード原則・TRIZ原理22・リフレーミングと正面衝突 |
| **第1版の推奨案C「二重処理型」**（まず処理をやり切ってから一つ持ち出す） | 2026-09-16 | 発動条件を逆に置いていた。処理が**できる**前提になっており、この思考法が最も必要な場面（権限・予算・時間がない）を定義から締め出していた |
| **第2版で二重効果と記録・報告を必須要素にしたこと** | 2026-09-16 | 個人の判断法に組織的な安全装置を混ぜていた。記録・報告ができるのは報告先と権限がある人だけで、必須にした時点で適用範囲を組織の従業員に限定していた。第3層・第4層へ分離 |
| **「段差の声掛けは安全実務と衝突する」という私の指摘** | 2026-09-16 | 片手落ち。残留リスクの周知＋暫定措置は安全実務の標準手順であり、衝突しない。詳細は `00_CONCEPT_REVISION.md` 第2章 |

## 現在の仮定（すべて検証対象）

- A1. 現場の人が求めているのは「前向きになる方法」ではなく「次に何をするか」【推・未検証】
- A2. 事例の密度が商品価値を決める（思想の新しさではない）【推】
- A3. 「うまくしのげた」ことが「改善が遠のいた」ことを意味する場合がある【推】。第4層はこれへの対処だが、任意層に置いたため、組織向け教材では必須として扱う必要がある
- A7. 事例をまたいで共通する選択基準が存在する【推・これがPhase 0.5の検証対象】
- A4. 最も刺さる読者は「教える立場の人」（店長・現場リーダー・個人店主）【推・未検証】
- A5. 一人で無理なく運営できる規模を優先する【前提】
- A6. 難解な理論を増やさない。日本語として分かる言葉を使う【前提】
