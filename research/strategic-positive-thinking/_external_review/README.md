# _external_review — 他のモデルによる独立検証

## 設計の意図

Claude 側の分析（発見1〜4、独自性の仮評価）を**先に見せない**状態で、
別のモデルに同じ事実から独立に判定させる。

理由: 結論を見せると追認が返る。追認は検証ではない。

## 手順

| 順 | ファイル | 目的 |
|---|---|---|
| 1 | `PROMPT_A_blind.md` | 事実のみを渡して独立判定させる。Claude の結論は一切含まない |
| 2 | （Aの回答を保存） | `RESPONSE_A_*.md` として保存 |
| 3 | `PROMPT_B_crosscheck.md` | Claude の発見を見せて、同意・反論を求める |
| 4 | （Bの回答を保存） | `RESPONSE_B_*.md` として保存 |
| 5 | 突き合わせ | 一致した点／食い違った点を `04_DIFFERENCES.md` に反映 |

## 見るべきポイント

- **A で挙がった既存概念が、Claude の ティア1リストと一致するか。**
  一致すれば、比較対象の選定は妥当。食い違えば、どちらかが見落としている
- **A が独自性を「低い」と判定した場合、その理由が Claude の懸念と同じか**
- **B で Claude の発見に反論が付くか。** 特に発見3（第4層の欠落が実害を生んだ）は
  1件の事例からの推論なので、別の読み方が出る可能性がある
