# 02_EXISTING_THEORIES — 比較対象の整理（Phase 1 の設計図）

最終更新: 2026-09-16
状態: **未調査**。本ファイルは現時点では「何を・どの順で・なぜ調べるか」の設計のみ。
各概念の中身（定義・目的・思考プロセス・共通点・相違点）はこれから埋める。

---

## 0. 整理の方針

本人の提示した20概念をそのまま順に調べるのは非効率である。理由は2つ。
1. 概念によって**独自性への脅威度が全く違う**。脅威の高いものから潰さないと、時間をかけた後に「やはり言い換えだった」と分かる最悪の順序になる。
2. 20概念のうち数個は、比較相手として**そもそも層が違う**（例: ストア哲学は人生態度、KYTは訓練手法、JTBDは市場分析枠組み）。同じ表で比べると混乱する。

そこで、**①脅威度で優先順位を付ける ②層（レイヤー）で分類する ③本人リストに無かった重要概念を追加する** の3点で整理した。

## 1. 層による分類

| 層 | 内容 | 該当概念 |
|---|---|---|
| L1 人生態度・哲学 | 生き方の構え | ストア哲学、The Obstacle Is the Way、アンチフラジャイル、レジリエンス |
| L2 心理・認知 | 個人の認知の操作 | ポジティブシンキング、リフレーミング、認知再構成（CBT）、ポジティブ心理学、意味づけコーピング、PTG／ベネフィット・ファインディング |
| L3 発想・推論 | 新しい着想の作り方 | アブダクション、クリティカルシンキング、TRIZ、セレンディピティ、制約による創造性 |
| L4 事業・意思決定 | 事業の進め方 | エフェクチュエーション、Jobs to be Done、デザイン思考、問題解決思考、アンチフラジャイル（事業面） |
| L5 組織・改善 | 組織の仕組み | KAIZEN、トヨタ生産方式、QCサークル、なぜなぜ分析、VOC活用、苦情処理（JIS Q 10002） |
| L6 安全・リスク | 危険の扱い | KYT、ヒヤリハット／ハインリッヒの法則、リスクアセスメント優先順位、安全文化 |
| L7 顧客接点・サービス | 現場の接客設計 | 顧客体験設計、サービスデザイン、サービスブループリント、ホスピタリティ、待ち行列の心理学、ピーク・エンドの法則、サービスリカバリー |
| L8 営業・対人実務 | 営業の技術 | 営業心理、アイスブレイク／前置き話法、クレーム対応実務 |
| L9 反対側の視点 | この思想を批判する側 | 感情労働、カスタマーハラスメント、ポジティブシンキング批判、有害なポジティブさ（toxic positivity） |

**戦略的プラス思考が現在いる層は L2 + L7 + L8 の重なり**だと考えられる【推】。
つまり「認知の操作」を「現場の接客・営業行動」に接続している点が現在地。ここが独自の座標になりうるかが Phase 2 の核心。

## 2. 優先順位（脅威度＝独自性を侵食する可能性）

### ティア1: 最優先で潰す（ここが黒なら概念を組み替える必要がある）

| # | 概念 | なぜ脅威か | 確認すべき点 |
|---|---|---|---|
| 1 | **エフェクチュエーション「レモネードの原則」**（S. Sarasvathy） | 「予期せぬ事態・失敗を資源として活用する」という原則そのもの。定義案Bとほぼ同義の恐れ | 原則の正確な記述、適用領域（起業家の意思決定に限るか）、現場接客への言及の有無 |
| 2 | **TRIZ 発明原理22「災い転じて福となす」**（Blessing in disguise / Turn lemons into lemonade） | 「有害な要素を有益な効果に変える」という原理が既に体系化・番号付けされている | 原理22の正確な定義、技術領域限定か、日本での普及度 |
| 3 | **リフレーミング／認知再構成（CBT）** | 「マイナスを別の枠で捉え直す」は完全に同じ動作 | 臨床的定義、行動変容まで含むか、「一つ取り出す」という制約の有無 |
| 4 | **KAIZEN／トヨタ生産方式（異常の見える化・なぜなぜ・ポカヨケ）** | 「ミス→仕組み改善」は完全にこの領域。現場日本語での既存最強概念 | 「異常を隠さず止める」思想、改善提案制度、現場の声掛け文化との関係 |
| 5 | **サービスリカバリー／サービスリカバリー・パラドックス** | 「クレーム→信頼」の主張の根拠であり、同時に反証の出所 | 実証の強さ（既に一部確認済: 満足度に限定） |

### ティア2: 差分を明確にすれば共存できる

| # | 概念 | 想定される差分の方向【推】 |
|---|---|---|
| 6 | ポジティブシンキング | 「良いと思い込む」vs「処理してから一つ取り出す」＝最も分かりやすい対比。宣伝文句として使える |
| 7 | アンチフラジャイル（Taleb） | システムの性質 vs 個人の即時行動。層が違う |
| 8 | ストア哲学／The Obstacle Is the Way | 態度・徳 vs 現場の行動手順。層が違う |
| 9 | レジリエンス | 回復する力 vs 転用する行動。目的が違う |
| 10 | デザイン思考／サービスデザイン | プロジェクト単位・設計行為 vs 秒単位・その場の即応。時間軸が違う |
| 11 | Jobs to be Done | 顧客の目的の解釈枠 vs 現場での行動選択。使う場面が違う |
| 12 | 顧客体験設計（CX）／ホスピタリティ | 設計思想 vs 個人の型。ホスピタリティとの違いは「効果を意図する」点か（要検討） |
| 13 | 問題解決思考／クリティカルシンキング | 正しく解く vs 副産物を取り出す。目的が違う（ただし「副産物」という言い方は弱い） |
| 14 | KYT／ヒヤリハット | **共通点が非常に多い**（危険に気づき、その場で共有する）。「KYTの接客版」と言われた時に何と答えるか、を用意する必要あり |
| 15 | アブダクション | 推論形式 vs 行動の型。層が違う |
| 16 | セレンディピティ | 偶然の幸運 vs 意図的な転用。むしろ対比に使える |

### ティア3: 反対側からの検証（この思想を殴る側）【本人リストに無し・重要】

| # | 概念 | 何を検証するか |
|---|---|---|
| 17 | **感情労働**（A. Hochschild） | 従業員に感情の管理を要求することの負荷。「マイナスを価値に変えろ」が労働強化になる境界 |
| 18 | **カスタマーハラスメント対策**（厚労省のマニュアル等） | 「クレームはチャンス」という教え方が、従業員保護の方針と矛盾しないか |
| 19 | **toxic positivity / ポジティブシンキング批判**（B. Ehrenreich 等） | 前向きさの強要が持つ害。この思想が同じ批判を受けない条件は何か |
| 20 | **リスク低減措置の優先順位**（厚労省） | 【確認済】声掛けは管理的対策＝下位。定義案Cの根拠 |
| 21 | 自己責任論／構造的問題の個人化 | 組織の問題を個人の心構えに転嫁する装置になっていないか |

### ティア4: 余力があれば

ナッジ／行動経済学、待ち行列の心理学（D. Maister）、ピーク・エンドの法則、
Appreciative Inquiry（問題でなく強みから始める＝対照的立場）、制約理論（TOC）、
逆転の発想（糸川英夫）、「禍を転じて福と為す」等の日本のことわざ・訓話、
VOC活用／NPS、JIS Q 10002（苦情対応）、行動観察・エスノグラフィ、
ポジティブ心理学の broaden-and-build 理論（Fredrickson）とその再現性議論。

## 3. 各概念で埋める共通テンプレート

```
### 概念名（原語 / 提唱者 / 年 / 主要文献）
1. 定義（一次資料の言葉で。出典URL必須）
2. 主な目的
3. 思考プロセス（手順があれば手順の形で）
4. 戦略的プラス思考との共通点
5. 相違点（層・時間軸・主体・目的のどれが違うか）
6. 独自性を侵食する可能性: 高 / 中 / 低 + 理由
7. この概念から借りられるもの（敵ではなく部品として使える点）
8. この概念から受ける批判（この思想への反論として最も鋭いもの）
```

※ 項目7・8は本人のテンプレに無かったが追加した。理由:
- 7 は、独自性がなかった場合に**組み合わせの部品**として再利用するため。
- 8 は、Phase 4（使わない場面）と 06_PRINCIPLES の制約条件の材料になるため。

## 4. Phase 1 の停止条件（判定基準）

Phase 1 を終えた時点で、以下のどれかに該当したら**概念を組み替える**。

- ティア1のうち **3つ以上が「侵食可能性: 高」** → 既存概念の言い換えと判定。定義を案A（接点特化）へ大幅に狭めるか、対象領域を絞って再設計する。
- ティア1の1・2（レモネード原則・TRIZ原理22）が**両方とも「高」** → 「マイナスから価値を取り出す」という主張自体は独自でないと確定。
  → その場合の残る独自性候補は「**日本の対面現場に限定した、秒単位の行動の型としての体系化**」のみ。そこに賭けるかを判断する。
- 「侵食可能性: 高」が0〜1 → 想定より強い。ただしその場合は**調査不足を疑う**こと。

## 5. 調査時のルール

- 一次資料（原著・論文・公式サイト）を優先。ブログのまとめは出典として使わない（発見の手がかりには使ってよい）。
- 引用は「」で囲み、出典URLと参照日を 11_REFERENCES.md に記録。
- 【事】【推】【未】の表記を全ファイルで統一。
- 日本語で流通している概念は、**日本語圏での使われ方**も調べる（英語の原義と現場での使われ方がズレていることが多い。例: リフレーミング、レジリエンス）。
