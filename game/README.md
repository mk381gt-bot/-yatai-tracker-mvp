# 天竜西遊 〜雲を越えて〜

羽のない東洋の龍に乗って雲海を飛ぶ、ブラウザ用のレールシューティングゲームです（試作版・1ステージ＋ボス）。

## 遊び方

- マウス（スマホは指でなぞる）で照準を動かす
- クリック（タップ）で龍珠弾を撃つ
- 押したまま照準で敵をなぞるとロックオン（最大6つ）、離すと追尾する光弾を一斉発射。まとめて倒すと連破ボーナス
- Q / E（スマホは ◀ ▶）で視点を前・右・後ろ・左に回す。敵の方向は右上のレーダーで確認
- 流れてくる仙桃を撃つと龍気（体力）が回復
- P で一時停止、M で音のオンオフ

## 起動方法

ES モジュールを使っているので、`index.html` をダブルクリックで開くだけでは動きません。
このフォルダでローカルサーバーを立てて開いてください。

```sh
cd game
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

GitHub Pages などの静的ホスティングに置けば、そのままスマホでも遊べます。

## ファイル

- `index.html` … 画面とタイトル・リザルト表示
- `main.js` … ゲーム本体（描画・敵・ボス・効果音・BGM）
- `three.module.min.js` … 3D 描画ライブラリ Three.js r170（MIT ライセンス、`THREE-LICENSE.txt`）

画像・音声ファイルは使っておらず、モデルはすべてコード上の図形の組み合わせ、音はすべてその場で合成しています。

## テスト用 URL オプション

- `?t=86` … 開始時刻を指定（86 でボス直前から）
- `?god` … ダメージを受けない
