# 6-1 最初の顧客像：3候補と推奨

## 評価の軸

| 軸 | 意味 |
|---|---|
| ローカルの必然性 | クラウドに出せない理由が、本人の気持ちではなく契約・取引先・法律にあるか |
| 定型業務の多さ | AIで効果が出やすい書類仕事が多いか |
| 自分の強みが効くか | 現場経験30年が、聞き取り・提案・信頼に効くか |
| 支払い能力 | 月3〜6万円＋機材を払えるか |
| 地域の数 | 袋井・磐田・掛川・浜松に候補企業が多いか |
| 事例の横展開 | 1社で作ったものが同業他社にも使えるか |

## 3候補

### 候補A：自動車・二輪部品の中小製造業（Tier2/3、従業員30〜150名）

- **困りごと**：OEM・Tier1から受け取る図面・仕様書・品質要求は「社外持ち出し禁止」。品質記録・不具合報告（是正処置書、8D等）・作業標準書が大量にあり、ベテランの頭の中にある過去事例を若手が探せない。取引先からセキュリティ対策の状況を問われる。
- **最初の業務**：過去の不具合・クレーム報告の類似事例検索＋是正処置書の下書き（L3、ローカル）
- **効果の測り方**：類似事例を探す時間、報告書作成時間

### 候補B：建設・土木・地盤改良の中小工事会社（従業員20〜80名）

- **困りごと**：施工計画書・安全書類・日報・写真台帳・見積など書類が多い。発注者の図面・入札関連情報は外に出しにくい。現場代理人の残業。
- **最初の業務**：日報・作業報告の要約、過去の施工計画書・事故ヒヤリハット事例の検索（L3）
- **効果の測り方**：書類作成時間、現場代理人の事務残業時間

### 候補C：社労士・税理士事務所など士業（従業員5〜30名）

- **困りごと**：顧客企業の個人情報・給与・税務情報を大量に扱う。守秘義務が厳格。法改正の調べ物が多い。
- **最初の業務**：所内マニュアル・過去の相談記録の検索（L3）、法改正の調査はクラウド（L1）
- **効果の測り方**：調べ物の時間、回答書の作成時間

## 比較

| 軸 | A 製造（部品） | B 建設・土木 | C 士業 |
|---|---|---|---|
| ローカルの必然性 | ◎ 取引先契約で明確 | ○ 発注者による | ◎ 守秘義務・個人情報 |
| 定型業務の多さ | ◎ 品質文書 | ◎ 安全・施工書類 | ○ |
| 自分の強みが効くか | ○〜◎ 製造経験 | ◎ 土木・地盤改良30年 | △ 業務知識が薄い |
| 支払い能力 | ◎ | ○ | ○（小規模） |
| 地域の数 | ◎ 西部は部品メーカーの集積地［推定］ | ○ | ○ |
| 事例の横展開 | ◎ 同業・同じ取引先の系列に広がる | ○ | ○ |
| 課題 | 社内の情報管理ルールが厳しく、導入審査に時間がかかる | ITへの抵抗感、現場が忙しく試す時間が取れない | 1社あたりの規模が小さい |

## 推奨

**仮決め：** **候補A（自動車・二輪部品の中小製造業）**を最初の主力ターゲットにする。
- 理由：
  1. 「ローカルでなければならない理由」が取引先との契約で明確 → 「なぜクラウドじゃダメなのか」の説明が不要。
  2. 品質文書は形式が決まっており、過去事例検索・報告書下書きの効果が出やすい［推定］。
  3. 支払い能力があり、取引先から求められるセキュリティ対策の「証跡」（点検報告書）にも価値がある。
  4. 同じ取引先系列の他社に横展開しやすい。
- 別案：**候補B（建設・土木）を最初の1社に**する。みーぴーさんの人脈・経験が最も直接効き、紹介で最初の1社を取りやすい可能性がある。**人脈で今すぐ話を聞いてくれる会社がBにあるなら、PoCはBから始める方が早い**（この判断はみーぴーさんの人脈次第＝[08-open-issues.md](../08-open-issues.md)）。
- Cは2年目以降の横展開先。

## 最初の会社を見つける方法

1. 既存の人脈（元の職場、取引先、協力会社）から「話を聞かせてほしい」と10社に声をかける（売り込みではなく、困りごとの聞き取り）
2. 商工会議所・商工会のセミナーで「社外に出さないAI活用」の講座（60分）を開く
3. 地域の金融機関（信用金庫等）の取引先向けビジネスマッチング
4. 聞き取りで「取引先からAIへの入力を禁止されている」会社を優先
