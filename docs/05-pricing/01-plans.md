# 5-1 価格プラン（導入費＋月額保守）

## 価格の考え方

- **時間単価の目安：1万円／時間**［推定］。根拠：地域のIT保守・PCサポートの技術料（時間あたり8千〜1.2万円程度が一般的と推定）と、AI専門性の上乗せの中間。
- 月額保守 ＝ 想定工数（時間）× 1万円 を基本に、監視・ツール費を含めて丸める。
- 機材は**顧客が実費で購入**（当社は選定・発注支援・設定。仕入れ・転売はしない）。

## 価格についての仮決め

**仮決め：** スタンダード 導入60万円／月額6万円を「主力」に置く。
- 理由：顧客から見て「月6万円＝事務員1人の月給の1/4程度」で説明しやすい［推定］。当社から見て1社6h/月で時間単価1万円を確保。
- 別案：月額を下げて（例：4万円）初期の契約数を優先する。→ 一人で回せる社数の上限に早く達し、3年目の売上上限が下がる。

**仮決め：** 最低契約期間12か月、PoCは有償（20万円）。
- 理由：無償PoCは「お試しで終わる」顧客を呼び込む。導入費からの差引で本導入の動機になる。
- 別案：最初の1社だけは無償PoC（実績づくり優先、事例公開を条件に）。

## 補助金の扱い

- ［調査］IT導入補助金は「デジタル化・AI導入補助金」に名称変更（令和7年度補正〜）。補助率最大4/5、補助額最大450万円との解説あり［要確認：公募要領］。
- 補助金の対象になるには、当社（またはパートナー）が「IT導入支援事業者」として登録し、ツールを登録する必要がある［要確認］。機材（ハード）が対象になる枠は限られる［要確認］。

**仮決め：** 1年目は補助金を前提にしない価格で売り、補助金対応は2年目に検討（または登録済みの地元IT業者と組む）。
- 理由：登録手続き・事務負担が一人には重い。補助金待ちで導入時期が遅れる。
- 別案：初年度から登録済み事業者と提携し、補助金込みの提案で受注率を上げる。
