# 2-2 責任範囲と契約書の要点

> 注意：以下は契約書作成のための「論点メモ」であり、法的助言ではない。**正式な契約書は弁護士のレビューを受ける**（費用 15〜30万円程度［推定］、タスク T-12）。

## 契約の構成

| 契約 | 性質 | 内容 |
|---|---|---|
| ① 基本契約＋秘密保持契約（NDA） | — | 最初に締結。秘密情報の範囲、目的外利用禁止、返還・削除 |
| ② 導入業務 個別契約 | **請負**（成果物：稼働する社内AI環境＋手順書＋研修） | 検収基準・検収期間を明記 |
| ③ 保守点検 個別契約 | **準委任**（点検という「作業の実施」を約束し、結果＝AIの正確さは約束しない） | 点検項目・頻度・報告書・相談窓口の範囲 |
| ④ 個人情報の取扱いに関する覚書 | — | 個人情報を扱う可能性がある場合の安全管理措置（[03-laws.md](03-laws.md)） |

**仮決め：** 導入＝請負、保守＝準委任。
- 理由：導入は「動く環境」が明確な成果物にできる。保守で「AIの出力品質」を結果保証すると責任が無限に広がる。
- 別案：導入も準委任にする（要件が曖昧な顧客の場合は安全。ただし顧客から見て「何が納品されるか」が分かりにくい）。

## 責任範囲（誰が何に責任を持つか）

| 項目 | 当社 | 顧客 | メーカー等 |
|---|---|---|---|
| 機材の選定・設定 | ○ | | |
| 機材の所有・設置場所・電源・ネットワーク | | ○ | |
| 機材のハード故障の修理 | 取次 | | ○（メーカー保守） |
| OS・推論エンジン・管理画面の更新 | ○（保守契約の範囲） | | |
| どの文書をAIに登録するかの判断 | 助言 | ○ | |
| AIの回答を業務に使うかの最終判断 | | ○ | |
| 社員への社内ルール周知・アカウント管理 | 助言・手順提供 | ○ | |
| クラウドAIサービス自体の障害・規約 | | ○（契約者） | ○（提供者） |

**仮決め：** 機材は**顧客名義で購入**（当社は選定・設定のみ。転売・リースはしない）。
- 理由：在庫・故障・所有権のリスクを当社が持たない。補助金申請でも顧客の資産になる方が単純［推定］。
- 別案：当社がリース／レンタル提供（月額に機材代を含める。顧客の初期負担は減るが、資金負担と故障リスクを当社が持つ）。

## 免責（主な条項案）

1. **AI出力の非保証**：生成AIの回答には誤りが含まれ得る。当社は回答の正確性・完全性・特定目的への適合性を保証しない。業務判断は顧客が行う。
2. **第三者製品**：機材・OS・オープンソースソフト・モデル・クラウドAIの不具合や仕様変更、提供終了による損害は免責（ただし当社は代替策の提案に努める）。
3. **不可抗力**：天災・停電・通信障害・未知の脆弱性を突いた攻撃（当社に過失がない場合）。
4. **顧客側の原因**：顧客によるルール違反、無断の設定変更、アカウントの管理不備。
5. **データ**：バックアップは当社の作業として行うが、データ消失の最終責任は所有者である顧客（当社の過失による消失を除く）。

## 損害賠償の上限

- **上限：「損害発生の原因となった個別契約に基づき、直近12か月に顧客が当社に支払った対価の総額」**
- 範囲：通常かつ直接の損害に限る。逸失利益・間接損害は除く。
- 例外：**当社の故意または重大な過失による場合は上限を適用しない**（上限条項があっても、故意・重過失の場合は無効と判断される可能性が高いため、最初から明記して信頼を得る）［推定：一般的な裁判例の傾向］。
- 秘密情報の漏えいについては、上限を「対価総額」とするか別枠（例：1,000万円）にするかが論点。
- **前提：2026年11月時点で保険は未加入。** 別枠は保険で支払える範囲でしか設定できないため、**保険の見積・加入（T-13）が済むまでこの論点は決められない**。

**仮決め：** 賠償上限は直近12か月の対価総額。漏えいも同じ上限。
- 理由：一人事業で負える範囲に抑える。保険が無い状態でも自己資金で負える額に留まる。保険（[04-insurance.md](04-insurance.md)）加入後に上乗せを検討する。
- 保険加入までの扱い：**保険に入るまでは、顧客と保守契約・PoC契約を結ばない**（遠隔接続や機密文書の取扱いが始まるため）。
- 別案：漏えいのみ上限 1,000万円とし、顧客の安心感を高める。**サイバー保険の支払限度額が1,000万円以上ある場合に限る**（保険なしで1,000万円の別枠は、一人事業では負えない）。

## SLA（サービスレベル）の要点

単一の機材で動くため、**稼働率の「保証」はしない**。目標値（SLO）として示し、未達時の減額はプレミアムのみ。

| 項目 | ライト | スタンダード | プレミアム |
|---|---|---|---|
| 受付時間 | 平日 9–17時（メール・フォーム） | 平日 9–17時（メール・電話） | 平日 8–18時（メール・電話・チャット） |
| 初動（受付から最初の回答） | 2営業日以内 | 翌営業日以内（重大障害は4営業時間以内） | 4営業時間以内（重大障害は2営業時間以内） |
| 復旧目標（ソフト起因） | 5営業日 | 3営業日 | 翌営業日 |
| 復旧目標（ハード故障） | メーカー保守に準ずる | メーカー保守に準ずる＋代替機の手配支援 | 同左＋当社保有の代替機を貸出（在庫がある場合） |
| 稼働率目標（営業時間内） | 設定なし | 95% | 97% |
| 未達時 | — | — | 当月保守料の10%を翌月減額（上限：当月保守料の30%） |
| 訪問 | 別料金 | 年2回含む | 毎月1回含む |

「重大障害」＝全社員がAIを使えない状態、または情報漏えいの疑い。

## その他の重要条項

| 条項 | 要点 |
|---|---|
| 契約期間・解約 | 保守は最低12か月、以後1年自動更新。解約は3か月前通知 |
| 再委託 | 代替要員への再委託を可能とする（事前通知、同等の秘密保持義務を課す） |
| 事業継続 | 当社が業務継続不能になった場合、管理者パスワード・手順書を顧客に引き渡す（封緘保管） |
| 契約終了時 | 遠隔接続の撤去、当社側の認証情報削除、削除証明書の発行 |
| 知的財産 | 顧客データ・成果物（顧客専用の設定・テンプレート）は顧客に帰属。当社の汎用ノウハウ・点検手順は当社に帰属 |
| 価格改定 | 機材・クラウド費用の高騰時は、3か月前通知で改定可 |
| 反社条項・準拠法・管轄 | 静岡地方裁判所（浜松支部）を第一審の専属的合意管轄に［要確認］ |
