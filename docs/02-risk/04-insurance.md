# 2-4 サイバー保険・賠償責任保険の要否

## 結論

| 保険 | 要否 | 理由 |
|---|---|---|
| **IT業務賠償責任保険（受託業務の過失による賠償）** | **必須** | 設定ミスで顧客の業務が止まった・データが消えた等の賠償に備える。契約の賠償上限と組み合わせる |
| **サイバー保険（情報漏えい・不正アクセス）** | **必須** | 当社は複数顧客に遠隔接続を持つため、当社が侵害されると全顧客に波及する。調査費用・通知費用・賠償をカバー |
| 施設・業務遂行中の賠償（対人・対物） | 推奨 | 訪問設置時に顧客の設備を壊した等。上記にセットされることが多い |
| 所得補償（就業不能） | 推奨 | 一人事業の最大リスクは本人の病気・けが |
| 機材の動産保険 | 不要（標準） | 機材は顧客所有（仮決め）。自社検証機のみ火災保険等で対応 |

## 選ぶときの確認項目

- 「受託したIT業務（設定・保守）」が補償対象業種に入っているか（AI関連業務の扱い）
- 他人から預かったデータ（受託物）の損壊・漏えいが対象か
- 遠隔保守中の事故が対象か
- 支払限度額：**1事故 5,000万〜1億円**を目安（契約上の賠償上限より大きく）
- 免責金額（自己負担額）
- 事故対応サービス（フォレンジック調査会社・弁護士の紹介）が付くか

## 保険料の目安

［調査］フリーランス向け保険の相場は月額500〜3,000円程度との記事あり（補償内容は商品で差が大きい）。
［推定］IT業務賠償＋サイバーを法人・個人事業向けに個別加入した場合、売上1,000万円未満・限度額1億円で**年5万〜15万円程度**。→ 収支試算では **年10万円（1年目）／15万円（3年目）** を計上。

候補の窓口（いずれも［要確認］）：
- 商工会議所・商工会の会員向け保険制度（ビジネス総合保険、サイバーリスク保険など）
- フリーランス協会などの会員向け賠償責任保険（会費に付帯するタイプ。補償額が小さめの場合あり）
- 損保各社の「IT業務賠償責任保険」「サイバー保険」（代理店経由で2〜3社から見積）

**仮決め：** 商工会議所経由の保険を第一候補に見積を取る。
- 理由：地元での信用（会員であること自体が営業にも効く）と、中小向けに保険料が抑えられた制度がある可能性が高い［推定］。
- 別案：損保の代理店経由で IT業務賠償＋サイバーの専用商品（補償が厚いが高め）。
