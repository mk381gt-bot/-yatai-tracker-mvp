# 1-1 事業の概要：誰に・何を・なぜ今

## 一言でいうと

「社外にデータを出せない会社の中に、AIを置いて、毎月点検する」。
機密・定型業務は社内のローカルAIで、高度な推論はクラウドAIで――この**使い分けの設計から保守まで**を、地元で一人の専門家が請け負う。

## 誰に（ターゲット）

| 項目 | 内容 |
|---|---|
| 地域 | 静岡県西部（袋井・磐田を中心に、掛川・浜松・森町まで車で1時間圏） |
| 規模 | 従業員 20〜150名の中小企業（IT専任者がいない、またはいても1名） |
| 業種 | 製造（自動車・二輪部品の Tier2/3、機械加工）、建設・土木・地盤改良、など。詳細は [06-first-customer/01-candidates.md](../06-first-customer/01-candidates.md) |
| 状況 | ・取引先（元請・OEM・発注者）から「図面・仕様をクラウドAIに入れるな」と言われている<br>・社長はAIを使いたいが、情報漏えいが怖くて止まっている<br>・ChatGPT等を社員が勝手に使っている（シャドーAI）のが心配 |

**仮決め：** 対象は従業員20〜150名の会社に絞る。
- 理由：20名未満はクラウドAIの個人利用で足り、月額保守を払う余力が小さい。150名超は情報システム部門があり、大手SIerと競合する。
- 別案：10名規模の士業・設計事務所も対象にする（個人情報・機密が多い）。

## 何を（提供価値）

1. **導入**：業務の聞き取り → 「ローカルでやる業務／クラウドでよい業務」の仕分け → 機材選定 → 社内AI（チャット＋社内文書検索）の構築 → 社内ルール作成 → 操作研修
2. **月額保守点検**：定期点検（動いているか）・安全点検（漏れていないか、改ざんされていないか）・精度点検（使える答えが出ているか）・相談窓口
3. **改善**：使われ方を見て、定型業務（日報要約、報告書下書き、過去事例検索など）を少しずつ増やす

「AIを入れて終わり」ではなく、**土木・製造の現場の"点検文化"をAIに持ち込む**のが売り（定期点検・記録・是正のサイクル）。

## なぜ今か

| 変化 | 内容 | 根拠 |
|---|---|---|
| 小さな機械で実用的なAIが動く | 128GB級の統一メモリを持つ小型機（NVIDIA GB10系、Apple M系、AMD Ryzen AI Max系）で、20B〜120B級のオープンモデルが社内で動く | ［調査］DGX Spark 128GB 等。[03-design/05-hardware.md](../03-design/05-hardware.md) |
| 日本語に強いオープンモデルが出揃った | 2026年2月に東京科学大・産総研が Qwen3 Swallow / GPT-OSS Swallow を公開（Apache 2.0） | ［調査］sources.md S-11, S-12 |
| 商用利用しやすいライセンス | Qwen3・gpt-oss が Apache 2.0 | ［調査］sources.md S-9 |
| 法律が厳しくなる | 改正個人情報保護法が 2026年7月17日公布（課徴金制度の新設など、施行は公布から2年以内） | ［調査］sources.md S-13 |
| 補助金の名称にAIが入った | IT導入補助金が「デジタル化・AI導入補助金」に名称変更（令和7年度補正〜） | ［調査］sources.md S-15 |
| 取引先からの要求 | 自動車業界のサプライチェーン向けセキュリティガイドライン（自工会・部工会）対応が中小部品メーカーにも求められている | ［推定］業界での一般的状況。個別企業で要確認 |

### 逆風（正直に）

- **機材価格の高騰**：メモリ・GPUが2025年末から大きく値上がり（RTX 5090 は国内で約74万円〜100万円超との報道）。［調査］S-16, S-17 → 機材は「GPUカード単体」より「統一メモリの小型機」を標準にする（[05-hardware.md](../03-design/05-hardware.md)）。
- **クラウドAIの安全性向上**：法人向けクラウドAIは「学習に使わない」契約が普通になった。→ 「全部ローカル」ではなく「使い分け」を売りにする理由はここ。
