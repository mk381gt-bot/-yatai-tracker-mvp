# 4-1 保守点検メニュー

土木・製造の「点検」の考え方をそのまま使う：**決まった項目を・決まった頻度で・記録に残し・異常があれば是正する**。

## 4つの点検

| 点検 | 目的（一言） | 主な中身 | 方法 |
|---|---|---|---|
| **① 定期点検** | 動いているか | 稼働状況、温度、ディスク残量、バックアップ成否、エラーログ、ソフト更新、UPS状態 | 自動監視＋遠隔 |
| **② 安全点検** | 漏れていないか・改ざんされていないか | 公開ポート確認、アカウント・権限の棚卸、脆弱性情報の確認と更新、モデルのハッシュ照合、遠隔接続ログ、クラウドAI利用の抜き取り確認 | 遠隔＋（年1回）訪問 |
| **③ 精度点検** | 使える答えが出ているか | 固定の評価質問セット（顧客業務から20問）で回答を採点、👎フィードバックの分析、文書索引の更新漏れ確認、テンプレートの改善 | 遠隔（採点は中身を見るため、顧客同席または顧客側で実施） |
| **④ 相談窓口** | 困りごとを解決 | 使い方の質問、新しい業務への使い方提案、社内ルールの相談 | メール・電話・（プランにより）訪問 |

**仮決め：** 精度点検の採点（回答の中身を見る作業）は、**顧客担当者と画面共有で一緒に行う**か、**当社が作った採点表で顧客が自分で採点**する。
- 理由：「中身を見ない点検」の原則（個人情報・機密に触れない）を守るため。
- 別案：当社が中身を見て採点（効率的だが、委託先としての個人情報取扱いが確実に発生する）。

## 頻度（プラン別）

| 項目 | ライト | スタンダード | プレミアム |
|---|---|---|---|
| 自動監視（死活・温度・容量・バックアップ） | 常時 | 常時 | 常時 |
| ① 定期点検（遠隔） | 月1回 | 月1回 | 月1回 |
| ② 安全点検（遠隔） | 四半期1回 | 月1回 | 月1回 |
| ② 安全点検（訪問：物理・設置環境） | 年1回 | 年2回 | 月1回（訪問点検に含む） |
| ソフト更新（検証機で確認後） | 四半期1回＋緊急時 | 月1回＋緊急時 | 月1回＋緊急時 |
| ③ 精度点検 | 半年1回 | 四半期1回 | 月1回 |
| モデルの見直し・提案 | 年1回 | 年2回 | 四半期1回 |
| バックアップ復元テスト | 年1回 | 半年1回 | 四半期1回 |
| ④ 相談窓口 | メール 月2件まで | メール・電話 月4時間まで | メール・電話・チャット 月8時間まで |
| 点検報告書 | 四半期ごと | 毎月 | 毎月＋年次報告会 |
| 改善作業（テンプレ追加等） | 別料金 | 月1時間まで含む | 月3時間まで含む |
| 想定工数（当社） | 約3時間/月 | 約6時間/月 | 約12時間/月 |

## 点検報告書（毎月／四半期）の構成

A4 1〜2枚。顧客が取引先や監査に出せる形にする。

1. 総合判定（良好／要注意／要対応）
2. 稼働状況（稼働率、停止があれば原因と対応）
3. 安全点検の結果（更新したソフトと版、確認した脆弱性情報、権限棚卸の結果、遠隔接続の記録）
4. 精度点検の結果（評価質問の合格数の推移）
5. 利用状況（利用者数・利用回数の推移、よく使われた業務）
6. 是正・改善の提案

## 緊急対応の流れ

1. 検知（監視の通知 or 顧客からの連絡）
2. 初動（プランの初動時間内に、状況確認と暫定対応の連絡）
3. 切り分け（ソフト → 当社が復旧／ハード → メーカー保守に取次）
4. 情報漏えいの疑い → 遠隔接続を即時停止、顧客へ報告（目安24時間以内）、記録保全、保険会社へ連絡
5. 復旧後、原因と再発防止策を報告書にまとめる
