## ② 安全点検（漏れていないか・改ざんされていないか）

| No | 点検項目 | 確認方法・基準 | 判定 | メモ |
|---|---|---|---|---|
| S-01 | アカウント・権限の棚卸 | 退職者・異動者のアカウントがない。管理者権限は最小人数（顧客の名簿と照合） | | |
| S-02 | 待ち受けポート | 推論エンジンは 127.0.0.1 のみ。外部公開ポートなし（一覧を保存） | | |
| S-03 | 外向き通信 | 許可した宛先（クラウドAI・更新サーバー・監視・VPN）以外への通信がない | | |
| S-04 | モデルのハッシュ照合 | 全モデルの SHA-256 がモデル台帳と一致 | | |
| S-05 | 脆弱性情報 | OS・推論エンジン・管理画面・VPNの脆弱性情報を確認。重大なものは更新済み（版を記録） | | |
| S-06 | ソフト更新 | 検証機で確認済みの版に更新。更新前バックアップ取得済み | | |
| S-07 | 遠隔接続ログ | 当社の接続記録が作業記録と一致。不明な接続なし | | |
| S-08 | VPNの端末一覧・ACL | 承認済み端末のみ。ACLが標準設定から変更されていない | | |
| S-09 | クラウドAI利用の抜き取り | クラウド送信履歴から抜き取り確認し、L3（機密）らしき入力がない（顧客立会または顧客確認） | | |

| S-11 | 物理（訪問時） | 施錠、設置環境（温度・粉塵・配線）、機材ラベル | | |
